Informasi Sistem

Sistem Informasi Data Mahasiswa adalah sistem web sederhana yang dibuat untuk membantu pendataan bagi suatu universitas, mulai dari menampilkan data mahasiswa, mencatat, hingga memanajamen data mahasiswa.

Tentang Sistem

Sistem ini dibuat untuk memenuhi tugas praktikum mata kuliah Pemrograman Web judul 1, yaitu HTML & HTML5
